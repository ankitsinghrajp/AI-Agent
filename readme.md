# What is AI? 
 --> AI is the branch of Computer Science that enables machines to perform tasks that typically requires human intelligence.

 --> AI refers to the simulation of human intelligence in machines that are programmed to think, learn, and make decisions like humans.


 # What is an AI Agent? 

 --> An AI agent is an autonomous entity (software or robot) that perceives its enviroment, makes decisions, and performs actions to achieve specific goals using Artificial Intelligence techniques.
